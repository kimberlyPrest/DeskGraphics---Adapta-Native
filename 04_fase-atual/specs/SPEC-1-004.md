# SPEC-1-004 — Modelo Central, Fixture e Dashboards v1

**Fase:** 1 · **Levas:** A (T1.1, T1.2), C (T1.4, T1.5), D (T1.6) · **CAs:** CA-1-12..18

## Objetivo
Criar o modelo de dados centralizado do funil, a fixture sintética e o Dashboard v1 — visão de funil, campanhas e lista de oportunidades — tudo sobre dados sintéticos, sem integração.

## Escopo
- **T1.1** — Fixture sintética: leads com origem/campanha/peça, SQLs, estágios, vendas/perdas com motivo (sem PII real)
- **T1.2** — Modelo de dados: lead (origem, campanha, peça, datas), estágio (histórico com timestamps), venda (valor, data), perda (motivo)
- **T1.4** — Dashboard v1 funil: volume por estágio, conversão etapa a etapa, tempo mediano por etapa
- **T1.5** — Dashboard v1 campanhas: leads por campanha/peça, custo, CPA, conversão por campanha
- **T1.6** — Lista de oportunidades com critérios versionados (ex.: parado + engajamento = quente)

## Critérios de aceite
- **CA-1-12** — Fixture sintética carrega no modelo sem erro e sem PII
- **CA-1-13** — Modelo registra histórico de estágios com timestamps (não só estado atual)
- **CA-1-14** — Modelo central consultável: leads, campanhas, estágios, vendas e perdas
- **CA-1-15** — Re-carga da fixture é idempotente (não duplica)
- **CA-1-16** — Dashboard funil exibe volume, conversão por etapa e tempo mediano (dados sintéticos)
- **CA-1-17** — Dashboard campanhas exibe leads, custo e CPA por campanha/peça (dados sintéticos)
- **CA-1-18** — Lista de oportunidades aplica critérios versionados e prioriza; banner "dados de demonstração" visível enquanto a fixture estiver ativa

## TDD
- **RED:** carga da fixture falha sem modelo / duplica sem idempotência
- **GREEN:** fixture carrega; dashboards e lista renderizam sobre ela
- **REGRESSÃO:** re-carga não altera contagens

## Dependências
