# SPEC-1-004 — Modelo Central, Fixture Sintética e Dashboards v1

**Fase:** 1 · **Levas:** A (T1.1, T1.2), C (T1.4, T1.5), D (T1.6) · **CAs:** CA-1-12..18

## Objetivo
Fundação de dados sem integrações: modelo central do funil + fixture sintética + dashboards v1 (funil e campanhas) rodando com dados sintéticos.

## Escopo
- **T1.1** — Fixture sintética: leads com origem/campanha/peça, SQLs, estágios, vendas/perdas com motivo (sem PII real)
- **T1.2** — Modelo de dados: lead (origem, campanha, peça, datas), estágio (histórico com timestamps), venda (valor, data), perda (motivo)
- **T1.4** — Dashboard v1 funil: volume por estágio, conversão etapa a etapa, tempo mediano por etapa
- **T1.5** — Dashboard v1 campanhas: leads por campanha/peça, custo, CPA, conversão por campanha
- **T1.6** — Lista de oportunidades: tela com critérios versionados (ex.: parado ≥ X dias + engajamento)
- Banner visível "dados de demonstração" enquanto não houver ingestão real (Fase 2)

## Critérios de aceite
- **CA-1-12** — Fixture sintética carrega no modelo sem erro e sem PII
- **CA-1-13** — Modelo registra histórico de estágios com timestamps (não só estado atual)
- **CA-1-14** — Fixture idempotente: re-execução não duplica
- **CA-1-15** — Modelo pronto para receber ingestão real na F2 (contrato de campos documentado)
- **CA-1-16** — Dashboard v1 funil exibe dados sintéticos com banner de demonstração
- **CA-1-17** — Dashboard v1 campanhas exibe custo/CPA por campanha e peça (sintético)
- **CA-1-18** — Nenhum dado pessoal exposto sem base legal (integra com SPEC-1-005)
