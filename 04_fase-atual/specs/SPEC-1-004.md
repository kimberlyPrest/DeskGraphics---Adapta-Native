# SPEC-1-004 — Modelo Central, Ingestões e Dashboard v1

**Fase:** 1 · **Levas:** A (T1.1), C (T1.6), D (T1.7, T1.8), E (T1.9, T1.10) · **CAs:** CA-1-12..18

## Objetivo
Criar o modelo de dados centralizado do funil, as ingestões (HubSpot, Meta Ads) e o Dashboard v1 — visão de funil e de campanhas com dados reais.

## Escopo
- **T1.1** — Fixture sintética: leads com origem/campanha/peça, SQLs, estágios, vendas/perdas com motivo (sem PII real)
- **T1.6** — Modelo de dados: lead (origem, campanha, peça, datas), estágio (histórico com timestamps), venda (valor, data), perda (motivo)
- **T1.7** — Ingestão HubSpot → modelo central (idempotente, mapeamento de campos documentado)
- **T1.8** — Ingestão Meta Ads → modelo central (campanha, conjunto, peça, custo, CPA)
- **T1.9** — Dashboard v1 funil: volume por estágio, conversão etapa a etapa, tempo mediano por etapa
- **T1.10** — Dashboard v1 campanhas: leads por campanha/peça, custo, CPA, conversão por campanha

## Critérios de aceite
- **CA-1-12** — Fixture sintética carrega no modelo sem erro e sem PII
- **CA-1-13** — Modelo registra histórico de estágios com timestamps (não só estado atual)
- **CA-1-14** — Ingestão HubSpot idempotente: re-execução não duplica
- **CA-1-15** — Ingestão Meta Ads idempotente: re-execução não duplica
- **CA-1-16** — Dashboard v1 funil exibe dados reais com defasagem ≤ GATE-04
- **CA-1-17** — Dashboard v1 campanhas exibe custo/CPA por campanha e peça
- **CA-1-18** — Nenhum dado pessoal exposto sem base legal (integra com SPEC-1-005)

- **GREEN:** ingestões sobre fixture produzem modelo íntegro; dashboards renderizam
