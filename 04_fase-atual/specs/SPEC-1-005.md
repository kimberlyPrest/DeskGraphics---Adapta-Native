# SPEC-1-005 — LGPD e Governança de Dados

**Fase:** 1 · **Leva:** B (T1.11) · **CAs:** CA-1-19..22

## Objetivo
Documentar a base legal, opt-out, retenção e acessos antes de qualquer cadência tocar cliente (DEC-08: LGPD é pré-condição da F3, construída na F1).

## Escopo
- Política de dados: quais dados pessoais o sistema centraliza (leads, contatos, interações), finalidade, base legal (legítimo interesse comercial + consentimento de marketing quando aplicável)
- Opt-out: como o cliente sai de cadências (canal por canal)
- Retenção: prazo de guarda dos dados de leads não convertidos
- Acessos: quem vê PII no dashboard (papéis); segredos de API fora de prompt/repo

## Critérios de aceite
- **CA-1-19** — Política de dados documentada com base legal por tipo de dado
- **CA-1-20** — Mecanismo de opt-out definido por canal (e-mail, WhatsApp)
- **CA-1-21** — Política de retenção definida (prazo + o que acontece ao expirar)
- **CA-1-22** — Matriz de acesso a PII no dashboard (quem vê o quê) + segredos fora de repositório

## TDD
- **RED:** tentativa de exibir PII para papel sem permissão é bloqueada
- **GREEN:** papéis autorizados veem; não autorizados não veem
- **REGRESSÃO:** revogação de acesso tem efeito imediato

## Dependências
- Nenhuma técnica; aprovação do cliente é pré-condição da F3 (GATE-05)
